# راهنمای دقیق «وضعیت سامانه» — هر ردیف یعنی چه و باید چه باشد؟

این سند، جدول «تنظیمات سامانه → وضعیت سامانه» در پنل ادمین را ردیف‌به‌ردیف توضیح می‌دهد:
مقدار هر مورد یعنی چه، مقدار درست برای **اجرای محلی** چیست، و مقدار درست برای **هاست واقعی (production)** چیست.

| # | ردیف جدول | توضیح | لوکال (ویندوز شما) | هاست واقعی (production) |
|---|---|---|---|---|
| ۱ | **محیط اجرا** | مقدار `APP_ENV`. رفتارهای امنیتی (HTTPS اجباری، توکن قوی، محدودسازی نرخ اجباری) فقط در `production` سخت‌گیرانه اعمال می‌شود. | `development` ✅ | `production` — حتماً |
| ۲ | **حالت تلگرام** | مقدار `TELEGRAM_MODE`. «نظارت دوره‌ای» همان **polling** است (ربات خودش هر چند ثانیه پیام‌ها را می‌گیرد). گزینه دیگر **webhook** است (تلگرام پیام‌ها را به سرور شما push می‌کند). | `polling` ✅ (نیازی به دامنه ندارد) | `webhook` توصیه می‌شود (کارآمدتر)؛ polling هم کار می‌کند |
| ۳ | **نشانی عمومی** | مقدار `PUBLIC_BASE_URL`. مبنای ساخت لینک‌های پخش آنلاین، اتاق تماشا و درگاه پرداخت. | `http://127.0.0.1:8000` ✅ | `https://your-domain.ir` — **https اجباری است**، بدون `/` آخر |
| ۴ | **میزبان‌های مجاز** | مقدار `ALLOWED_HOSTS`. سرور فقط درخواست‌های با این Host را پاسخ می‌دهد (ضد حملات Host-Header). | `127.0.0.1,localhost` ✅ | `your-domain.ir,www.your-domain.ir` |
| ۵ | **محدودسازی نرخ** | مقدار `RATE_LIMIT_ENABLED`. سقف درخواست (پنل، لینک پخش، پرداخت) با ردیس کنترل می‌شود؛ ضد اسپم و ضد سوءاستفاده از لینک پخش. | `0` (غیرفعال) ✅ چون ردیس لوکال لازم نیست | `1` — **اجباری در production** (اعتبارسنجی شروع بدون آن خطا می‌دهد) |
| ۶ | **توکن ربات** | `BOT_TOKEN` از BotFather. | تنظیم شده ✅ | همان توکن |
| ۷ | **توکن پنل** | `ADMIN_API_TOKEN` — کلید ورود به پنل ادمین. | تنظیم شده ✅ | توکن ≥۳۲ کاراکتر تصادفی (`scripts/generate_secret.py`) |
| ۸ | **پایگاه‌داده** | `DATABASE_URL` — PostgreSQL. | تنظیم شده ✅ | تنظیم شده + **بک‌آپ روزانه** |
| ۹ | **ردیس** | `REDIS_URL` — کش، محدودسازی نرخ، صف. | تنظیم شده ✅ | تنظیم شده |
| ۱۰ | **Storage تلگرام** | `PRODUCTION_STORAGE_CHAT_ID` یا `TELEGRAM_STORAGE_CHAT_ID` — کانالی که ربات ادمین آن است و فایل‌های ویدئویی آنجا نگهداری می‌شوند. | تنظیم شده ✅ | تنظیم شده (کانال اختصاصی؛ ربات = ادمین) |
| ۱۱ | **الزام حقوق محتوا** | `CONTENT_RIGHTS_REQUIRED` + `CONTENT_RIGHTS_ACK` — تا زمانی که شما تأیید نکنید محتوای دارای حقوق ثبت‌شده منتشر نمی‌شود. مسئولیت حقوقی را صریح می‌کند. | فعال ✅ | فعال بماند؛ `CONTENT_RIGHTS_ACK=1` در .env |
| ۱۲ | **اعتبارسنجی شروع** | `STARTUP_VALIDATE` — در لحظه بالا آمدن، تنظیمات چک می‌شود؛ خطای پیکربندی زودتر معلوم می‌شود. | فعال ✅ | فعال بماند |
| ۱۳ | **کارهای نگهداری در ربات** | `RUN_MAINTENANCE_IN_BOT` — اگر فعال باشد پروسه ربات خودش حذف دلیوری‌های منقضی، انقضای اشتراک و… را انجام می‌دهد. | `0` (غیرفعال) ✅ | `0` بماند — پروسه **RUNTIME** جداگانه این کارها را می‌کند (باید روی هاست اجرا باشد) |
| ۱۴ | **اعلان‌ها در ربات** | `RUN_NOTIFICATIONS_IN_BOT` — یادآور اشتراک و اعلان‌ها داخل پروسه ربات. | `0` (غیرفعال) ✅ | `0` بماند — پروسه RUNTIME انجام می‌دهد |
| ۱۵ | **فهرست مجاز رسانه** | `MEDIA_UPSTREAM_ALLOWLIST` — فقط از این دامنه‌های https اجازه پخش/پروکسی وجود دارد (ضد SSRF). وقتی پخش آنلاین از Storage تلگرام یا فایل‌سرور خودتان است، نیازی به آن نیست. | تنظیم نشده ✅ قابل قبول | اگر منبع پخش خارجی دارید: دامنه‌های آن را با کاما بنویسید؛ در غیر این صورت خالی بماند |
| ۱۶ | **HTTPS آزاد برای رسانه** | `MEDIA_ALLOW_ANY_HTTPS` — اگر فعال باشد پخش از **هر** دامنه https مجاز می‌شود. راحت ولی خطرناک (SSRF/استفاده از سرور شما به‌عنوان پروکسی). | غیرفعال ✅ | غیرفعال بماند؛ فقط allowlist دقیق |

## جمع‌بندی برای وضعیت فعلی شما (لوکال)

جدول فعلی شما **برای اجرای محلی کاملاً سالم و درست** است. تنها موارد «تنظیم نشده» (فهرست مجاز رسانه و HTTPS آزاد) نباید برای اجرای محلی تنظیم شوند — اینها تنظیمات امنیتی منبع پخش هستند و خالی بودنشان یعنی «پخش فقط از Storage تلگرام» که درست است.

## نمونه `.env` برای هاست واقعی

```env
APP_ENV=production
TELEGRAM_MODE=webhook
PUBLIC_BASE_URL=https://your-domain.ir
ALLOWED_HOSTS=your-domain.ir,www.your-domain.ir
RATE_LIMIT_ENABLED=1
RATE_LIMIT_FAIL_CLOSED=0
TELEGRAM_WEBHOOK_SECRET=<رشته تصادفی حداقل ۱۶ کاراکتر>
BOT_TOKEN=<توکن BotFather>
ADMIN_API_TOKEN=<رشته تصادفی حداقل ۳۲ کاراکتر>
ADMIN_USER_ID=<شناسه عددی تلگرام شما>
BOT_USERNAME=<نام کاربری ربات بدون @>
DATABASE_URL=postgresql+psycopg://cinema_vault:<رمز قوی>@localhost:5432/cinema_vault
REDIS_URL=redis://localhost:6379/0
PRODUCTION_STORAGE_CHAT_ID=<شناسه عددی کانال ذخیره‌سازی>
RUN_MAINTENANCE_IN_BOT=0
RUN_NOTIFICATIONS_IN_BOT=0
CONTENT_RIGHTS_REQUIRED=1
CONTENT_RIGHTS_ACK=1
TELEGRAM_STORAGE_REQUIRED=1
STARTUP_VALIDATE=1
MEDIA_UPSTREAM_ALLOWLIST=
MEDIA_ALLOW_ANY_HTTPS=0
```

بعد از تغییر `.env`: مایگریشن + راه‌اندازی سرویس‌ها (API، MEDIA، RUNTIME و ربات polling یا ثبت webhook):
`python -m alembic upgrade head` سپس `deploy/production.ps1` (ویندوز) یا سرویس‌های systemd (لینوکس).
